## Highlights

| Area | What changed |
|------|----------------|
| **Gaps contract** | [GAPS.md](../GAPS.md) — what will never be added vs what may land in 1.x (inside fx’s grain). |
| **Failure policy** | [TRAP.md](../TRAP.md) — trap / abort / arena honesty. |
| **Backends** | [DRIVERS.md](../DRIVERS.md): emit-C is the supported fast path for hot/numeric work; QBE is not the speed story. Dual-emit equivalence gate named. |
| **License opinion** | [LICENSES.md](../LICENSES.md): no emit-C→MIT linking exception today. |
| **`std/wire`** | Endian `u16`/`u32` load/store + consume-or-Err foothold (prefer `--emit-c`). |
| **Linguist** | `.gitattributes` maps `*.fx` → Fx (avoids HLSL/FLUX mislabel). Host `*_ref.c` stays C on purpose. |
| **async** | Tombstoned on [SURFACE.md](../SURFACE.md) — use `std/nursery`. |

**Still not v1.0.** Further language lands (effects split, reborrow, Plain collections, …) stay pull-driven.

**Everyday path:** `gcc` + `fx run` / `--emit-c`. Product CLIs ship in **separate LedoCorp repos**.
