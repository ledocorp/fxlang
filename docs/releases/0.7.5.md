# fx 0.7.5 — composition under regions

**Language package** for [ledocorp/fxlang](https://github.com/ledocorp/fxlang)  
Docs: [ledocorp.org/fx](https://www.ledocorp.org/fx/) · [composition](https://www.ledocorp.org/fx/docs/composition/) · [surface](https://www.ledocorp.org/fx/docs/surface/)

Builds on the 0.7.4 composition method with typed pool ids, Map accumulate, and larger example programs. Tag: `v0.7.5`.

## Highlights

| Area | What shipped |
|------|-------------|
| **Typed pool `Id`** | `std/pool` / `lib/id_pool` — bare `i32` at get/set is a type error |
| **Map accumulate** | `map_add_i32` / `std/map.add_i32` (slot add or insert) |
| **Example programs** | `examples/composition_tally`, `examples/composition_reach` |
| **C interop helpers** | `fx bind` for inspectable stubs; Level 2 wrappers in `examples/bind_*` |
| **Docs / llms** | SURFACE + COMPOSITION + site parity |
| **Honesty** | No unsafe dialect; no growable `Vec` index assign |

## Install

```text
fx doctor
fx version                 # expect v0.7.5
fx new hello && cd hello && fx run main.fx   # exit 42
```

## Try

```text
fx run examples/composition_tally/main.fx
fx run examples/composition_reach/main.fx
fx run examples/pattern_pool/main.fx
fx run examples/tool_tally/main.fx
fx run examples/bind_smoke/main.fx --link examples/bind_smoke/host.c
```
