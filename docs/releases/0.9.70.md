# fx 0.9.70 — systems footing (freestanding · atomics · MMIO)

**Language package** for [ledocorp/fxlang](https://github.com/ledocorp/fxlang) 
**Tag:** `v0.9.70` (when published) 
**On** [0.9.69](0.9.69.md).

---

## Highlights

| Area | What landed |
|------|-------------|
| **`--freestanding`** | Compile with `-ffreestanding -fno-builtin`; implies `--no-zspec`. Hosted CRT still links for exit-code proof — not a `-nostdlib` / custom CRT0 product claim. A short note is written under `-o`. |
| **`Atomic<i32>`** | Explicit memory orders only (`order.relaxed` … `order.seq_cst`). Ops: `Atomic.new`, `.load`, `.store`, `.fetch_add` under `effects { atomic }`. emit-C → C11 `<stdatomic.h>`. |
| **MMIO + MmioCap** | `mmio_read32` / `mmio_write32` behind a minted **MmioCap** under `effects { mmio }`. emit-C → readable `volatile` via cap. Hosted mint proof for examples. |
| **Examples** | `examples/kern_atomic/`, `examples/kern_mmio/` (exit **42**). |
| **Contracts** | Facets / cap dictionaries from **0.9.69** remain. |

**IR note:** Atomic and MMIO IR paths are **out of scope** in this cut — prefer `--emit-c` or `--fallback-emit-c`. Freestanding IR is claimed with hosted CRT.

**Ship configs:** Auto · emit-C · IR when QBE staged (non-Atomic/MMIO) · GPL-3.0 · Win+Linux x86_64.

## Install

```text
fx doctor
fx version # expect v0.9.70
fx run examples/kern_atomic/main.fx --emit-c
fx run examples/kern_mmio/main.fx --emit-c
fx run main.fx --freestanding --emit-c # no-libc body; hosted CRT
```
