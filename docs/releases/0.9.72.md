# fx 0.9.72 — Serve season · thin teaching examples

**Language package** for [ledocorp/fxlang](https://github.com/ledocorp/fxlang)  
**Tag:** `v0.9.72` (when published)  
**On** [0.9.71](0.9.71.md).

---

## Highlights

| Area | What landed |
|------|-------------|
| **Serve / net (host tools)** | Local static HTTP (**fxserve**), workers, HTTPS (`--cert`/`--key`), handler foothold, and a wasm app proof live in the **monorepo / companion tool** path — not as a fat demo zoo inside this language zip. |
| **Web scaffold** | `fx new mysite web` drops a starter `site/` (T1). |
| **Packaging honesty** | Public `examples/` is a **T0 teaching set** only (showcases, tool_*, pattern_*, composition_*, `wasm_smoke`, one cap + one nursery smoke, …). Season proofs and wrap/tool twins are **not** mirrored here. |
| **Carry-forward** | IR for Atomic · MMIO · CapDict from **0.9.71**; facets, loans, iterate/FXCACHE, native-first Auto, GPL-3.0. |

**Everyday path:** `gcc` + `fx run` / `--emit-c`. Optional **clang** only for freestanding wasm32 experiments (`examples/wasm_smoke`). Product CLIs (fxrun, fxfetch, fxserve, …) ship in **separate LedoCorp repos** when published.

**Ship configs:** Auto · emit-C · IR when QBE staged · GPL-3.0 · Win+Linux x86_64.

## Install

```text
fx doctor
fx version # expect v0.9.72
fx new hello
fx run examples/showcase_core/main.fx
fx run examples/wasm_smoke/main.fx
fx new mysite web
```
