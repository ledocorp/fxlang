## Highlights

| Area | Change |
|------|--------|
| **`--use <dir>`** | Self-linking folder: include + lib dir + optional `dir/link.args` (FX-HOST-LINK) |
| **Hex / i32** | Values fitting `u32` but not signed `i32` (e.g. `0xFF0000FF`) adopt **i32 bit-patterns** (FX-FRICTION) |
| **Diags** | Struct field `;` → help “use `,` not `;` (fx is not C)” |
| **Agents** | llms / AGENT / WRAP / SURFACE routing: prefer `--use`, don’t invent winmm / std names; host+GUI → `--emit-c` |
