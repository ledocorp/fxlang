## Highlights

| Area | What landed |
|------|-------------|
| **Interior mut sugar** | No-grow `v[i]=x` on `Vec` under `effects { mut }` (same family as `vec_set`). Grow stays `push` / reassign. Soft-fx and growable realloc under index-assign stay refused. |
| **Living dogfood** | `examples/dogfood_pathc_slots` — dense SoA distance relax; dual-path exit **42**. |
| **CLI auto-host** | `fx build\|run … --cli` links `host/cli` + `host/process` so product tools need no author-written `host.c`. |
| **Dialect polish** | Contextual int literals / friction pack; host `--use <dir>` link units (from 0.9.61+). |

**Ship configs:** IR-native (default `fx run`) · emit-C first-class · host-linked CLI / guest / concur · Win + Linux x86_64 prebuilts.

## Honesty bounds

Still **not** in this tag:

- Soft / dynamic heap that erases region physics  
- Package **registry** (vendor / `fx.sum` pin only)  
- `fx run` forwarding program argv (use `--cli` / `--host`)  
- macOS prebuilt binary  
- Lexer keywords `nursery` / `spawn` / `await` / `Task<T>` (use `spawn_i32` / `await_i32`)  
- Generic `Chan<T>` as a finished dialect claim  
- DAP / mega-IDE product  
- Calling this release **v1.0**
