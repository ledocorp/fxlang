**Language package** for [ledocorp/fxlang](https://github.com/ledocorp/fxlang)

Maturity pack closeout. Tag: `v0.7.3`.

## Highlights

| Area | What landed |
|------|-------------|
| **Surface map** | As-implemented cheatsheet (`docs/SURFACE.md`) |

| **LLM surface** | `llms.txt` + SURFACE honesty aligned with pack |

## Install

```text
fx doctor
fx version                 # expect v0.7.3
fx new hello && cd hello && fx run main.fx   # exit 42
```

## Try

```text
fx run examples/tool_text/main.fx
fx run examples/tool_result/main.fx
fx run examples/tool_files/main.fx
fx run examples/showcase_072/main.fx
```
