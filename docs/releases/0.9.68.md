## Highlights

| Area | What landed |
|------|-------------|
| **License** | Product package and monorepo product code are **GNU GPL v3**. See [LICENSE](../../LICENSE), [NOTICE](../../NOTICE), [LICENSES.md](../LICENSES.md). |
| **Native-first `fx run`** | Default driver is **Auto**: try live `sh_*` first for programs in the supported set; otherwise the built-in fallback engine inside `bin/fx` (CLI: `--driver foundry`). `--driver sh` is the strict proof lane (no fallback). |
| **Wider live lane** | Many real demos stay on live Auto: Path C dogfood, tools, composition apps, concur footholds, `manifest_gate`, `std_path_smoke`, and related std surfaces (io read, path join, maps, Result/`?`, …). emit-C remains first-class; IR adds when claimed. |
| **Lexical loans** | Shared XOR mut on `&` / `&mut`, region-epoch escape (**FX0015**), borrow conflict (**FX0019**), Hylo call-end for inline `&mut` — no lifetime parameters. See [REGIONS.md](../REGIONS.md) · [SURFACE.md](../SURFACE.md). |
| **Inspectable compiler modules** | `compiler-source/` — fx lexer/parse/emit snapshots (read-only). Not a rebuild SDK; run `bin/fx`. |
| **Docs / version** | Package strings aligned to **0.9.68**; surface inventory includes full `std/`, concurrency, SIMD, `@override`. |

Language surface from **0.9.66** / **0.9.67** carries forward: no-grow `v[i]=x`, `--cli` auto-host, Path C dogfood, Surface / record `with` / asm / SIMD footholds — see [SURFACE.md](../SURFACE.md).

**Ship configs:** Auto driver (native-first) · IR-native on fallback path when QBE is staged · emit-C first-class · host-linked CLI / guest / concur · Win + Linux x86_64 prebuilts · Windows `qbe.exe` when staged · **GPL-3.0**.

## Honesty bounds

Still **not** in this tag:

- Soft / dynamic heap that erases region physics  
- Package **registry** (vendor / `fx.sum` pin only)  
- `fx run` forwarding program argv (use `--cli` / `--host`)  
- macOS prebuilt binary  
- Claiming **every** program runs on live `sh_*` without foundry fallback (only the sealed demo/corpus set is guaranteed)  
- `--cli` / `--host` on strict `--driver sh` (refused; use Auto / foundry)  
- Language-package TLS dial (`std/net.dial_tls` always fails; HTTPS via separate **fxfetch** tool)  
- Lexer keywords `nursery` / `spawn` / `await` / `Task<T>` (use `spawn_i32` / `await_i32`)  
- Generic `Chan<T>` as a finished dialect claim  
- DAP / mega-IDE product  
- Language-wide formal certification claims  
- Calling this release **v1.0**
