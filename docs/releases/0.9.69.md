## Highlights

| Area | What landed |
|------|-------------|
| **Scratch `fx run` + FXCACHE** | Default `fx run` (no `-o`) builds under a temp scratch and deletes it. Successful builds populate **FXCACHE** so identical re-runs can skip rebuild (`FX_CACHE=off` disables). |
| **`--watch`** | Debounced rebuilds; kills the previous child before restart; reuses FXCACHE when the fingerprint matches. `FX_WATCH_MAX` / `FX_WATCH_DEBOUNCE_MS` for harnesses. |
| **Local type elision** | `let x = 42;` when the initializer determines the type. **Parameters and returns stay explicit.** Surface JSON stays an exact API passport. |
| **Batch Vec init** | `let v: Vec<i32> = [40, 2];` expands to `vec_new` + `vec_push` (same grow physics as `v.push`; ≤32 elems). Plain `[T; N]` arrays unchanged. |
| **Diagnostics** | Borrow/effect failures (FX0019 / FX0023) emit an `= rewrite:` line with a concrete fix hint. |
| **Scaffolds** | `--scaffold tool` aliases `cli`; product CLIs teach `--cli` (no author `host_cli.c`). Grow teaching stays `v.push`. |
| **Guest reload recipe** | Host stay-up / guest rebuild notes under `examples/guest_plugin/` — no default dlopen. |
| **Surface (`fxsurface-2`)** | Param `loan` (`shared` / `exclusive` / `region`) + fn `loan_escape`; region/cap/override notes unchanged. See [SURFACE.md](../SURFACE.md). |
| **Auto live fallback** | If live `sh_*` emit fails at gcc, **Auto falls back** to the built-in engine inside `bin/fx` instead of hard-erroring. Strict `--driver sh` still shows the gcc error. |
| **Live IR arithmetic** | Expressions like `1 + 2 * 3` evaluate with normal precedence on the live IR path (exit **7**, not a last-literal trap). |

Language surface from **0.9.68** carries forward (GPL-3.0, native-first Auto, lexical loans, no-grow `v[i]=x`, `--cli`).

**Ship configs:** Auto · emit-C · IR when QBE staged · GPL-3.0 · Win+Linux x86_64.
