# fx 0.9.25 — SQLite file caps + host nursery (draft)

**Language package** for [ledocorp/fxlang](https://github.com/ledocorp/fxlang) 
**Tag:** `v0.9.25` (draft — not cut until publish) 
**Docs:** [ledocorp.org/fx](https://www.ledocorp.org/fx/)

On [0.9.2](0.9.2.md): SQLite file databases under `FsCap`, plus the host structured task nursery already in the monorepo lane.

---

## Highlights

| Area | What users get |
|------|----------------|
| **SQLite file + FsCap** | Open a DB file only when an `FsCap` allowlists the path; deny escapes; `:memory:` path unchanged |
| **Host task nursery** | `host/concur` create / spawn / join / shutdown (host C API — not language `spawn`) |
| **Prior 0.9.2 surface** | Host spine, NetCap allowlist (no dial), llhttp parse WRAP, `fx new --scaffold cli\|guest` |

**Ship configs:** unchanged from 0.9.2 — `ir-native` · emit-C first-class · host-linked CLI / guest.
