# fx 1.0.0 — first stable promise

**Language package** for [ledocorp/fxlang](https://github.com/ledocorp/fxlang)  
**Tag:** `v1.0.0`  
**On** [0.9.75](0.9.75.md).

This tag matches the guarantees in the private [V1_CRITERIA_LITE](https://github.com/ledocorp/fxlang) contract: Path C + Balance, permanent emit-C, dual-path culture, Win+Linux x86_64, argv via `--cli`/`--host`, GPL-3.0, tools as separate packs, foundry as workshop — plus **vendor-first** `std` resolve.

---

## Highlights

| Area | What changed |
|------|----------------|
| **Vendor-first** | When `vendor/std` is present and `fx.sum` verifies, `import std/…` resolves from **vendor** before staged `std/` / `FX_STD_ROOT` |
| **Pin gate** | Mismatched or missing `fx.sum` with `vendor/std` is a loud compile error |
| **Promise** | Public speech (NEXT / GAPS / SHIP / SURFACE / README) matches vendor-first; 1.x may deepen without Soft-fx |

**Everyday freezes (unchanged):** Windows + Linux x86_64 prebuilts; `fx run` does not forward argv; emit-C permanent; no Soft-fx.

**Everyday path:** `gcc` (or clang) + `fx run` / `--emit-c`. After install: `./scripts/verify-pack.sh` (or `.ps1`).

---

## Install

```text
fx doctor
fx version # expect v1.0.0
fx new hello
cd hello
fx run main.fx
# optional offline pin:
fx mod vendor
fx mod verify
fx run main.fx --emit-c
```

## Compatibility

Compatible with **0.9.75** programs. Projects that already commit `vendor/` + `fx.sum` now **compile from that tree** (intended). To use live package `std/` instead, remove or regenerate vendor after changing pins.
