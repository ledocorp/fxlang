# Compiler binaries

| File | Platform |
|------|----------|
| `fx.exe` | Windows x86_64 |
| `fx` | Linux x86_64 |

Put this directory on your `PATH`, then run `fx version` (expect **v0.9.1**).

These are the compilers for this package. You write `.fx` programs against the rest of the repository (`std/`, scaffolds, zspec headers).
