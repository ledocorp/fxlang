## Governance

fx is stewarded in a **primary-maintainer** model. Design, roadmap, and merge
authority rest with Shawn Londono / LedoCorp. There is no expectation of
community PR merge SLAs.

## Pull requests

**GitHub pull requests are not accepted** as a contribution channel.

Unsolicited PRs may be closed without review. If a change is invited, you will
be contacted through a channel designated by the maintainer.

## Issues

**GitHub Issues are welcome for now** for:

- Bug reports (repro steps, expected vs actual, fx version)
- Clear defect reports against published behavior

Please do **not** use Issues for large design debates, drive-by feature dumps,
or patch submission. A website form (or similar) may replace or supplement
Issues later (see http://www.ledocorp.org when available).

## Security

See [SECURITY.md](SECURITY.md). Do not file public Issues for sensitive
vulnerability reports.
